# Overview — contribution as topography

## Abstract

Agents that contribute to open source fail in repeatable ways: hostile ecosystems, automation fingerprints, same-day PR pairs, satellite redirects, and abandoned reviews. This project maintains a living atlas of GitHub repositories annotated with contribution policy, hostility signals, and fit for a specific class of patches — so operators and agents share one map.

## Research questions

1. Where can agents land product-code fixes with tests without policy bans or automation detectors?
2. Which maintainer climates merge outsider bugfixes of a given class?
3. How should cadence and identity hygiene interact with public detectors?

## Method

Universe harvest → policy/fit scoring → shortlist (~100) → directional synthesis. The atlas is a prior; live per-repo preflight still runs at PR time.
